## 📊 Scanner Types & Intervals

### 🔍 BB Scanner (Core) - Every 4 Hours
- **Purpose**: Swing trading and longer-term setups
- **Timeframes**: 4-hour and daily charts
- **Strategy**: Bollinger Band setups, pattern recognition
- **Schedule**: 00:00, 04:00, 08:00, 12:00, 16:00, 20:00
- **Logs**: `/opt/bb-screener/logs/bb_scanner_YYYYMMDD.log`

### 🚀 BB Scanner (Market Hours) - Every Hour
- **Purpose**: Day trading and intraday opportunities  
- **Timeframes**: 1-hour and 4-hour charts
- **Strategy**: More frequent scanning for day trading
- **Schedule**: Every hour 9:00-17:00, Monday-Friday
- **Logs**: `/opt/bb-screener/logs/bb_market_hours_YYYYMMDD.log`

### 📈 ICT Scanner - Every 4 Hours
- **Purpose**: ICT methodology analysis (gaps, Fibonacci, order blocks)
- **Timeframes**: 4-hour charts
- **Strategy**: ICT FVG, Fibonacci confluence, market structure
- **Schedule**: 00:30, 04:30, 08:30, 12:30, 16:30, 20:30
- **Logs**: `/opt/bb-screener/logs/ict_scanner_YYYYMMDD.log`

## 🎯 Key Differences

| Scanner | Frequency | Purpose | Best For |
|---------|-----------|---------|----------|
| **BB Core** | Every 4h | Swing trading | Medium-term positions |
| **BB Market** | Every 1h | Day trading | Intraday opportunities |
| **ICT** | Every 4h | ICT analysis | Technical setups |

## 🔧 Manual Commands

### Run Scanners Manually
```bash
# BB Scanner (Core)
timeout 1800 python main_scanner.py

# BB Scanner (Market Hours)  
timeout 1800 python main_scanner.py

# ICT Scanner
timeout 900 python ict_scanner_4h_r8.py
```

### Check Scanner Status
```bash
# View cron jobs
crontab -l

# Check recent logs
tail -50 /opt/bb-screener/logs/bb_scanner_$(date +%Y%m%d).log
tail -50 /opt/bb-screener/logs/ict_scanner_$(date +%Y%m%d).log
tail -50 /opt/bb-screener/logs/bb_market_hours_$(date +%Y%m%d).log

# Check running processes
ps aux | grep python
```

### Database Operations
```bash
# Export database
python enhanced_export.py

# Check scanner data
python check_bb_trades.py
python check_dashboard_data.py
```
